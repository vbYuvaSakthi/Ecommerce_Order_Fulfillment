# E-Commerce Order Fulfillment Analytics

Simple ETL and Data Warehouse project built using Python, MySQL, and Power BI to analyze order fulfillment and delivery performance.

## Project Flow

→ Python ETL (Extract, Transform, Load)
→ MySQL Data Warehouse
→ SQL Views (Order & Delivery Analytics)
→ Power BI Dashboard
→ Business Insights

## Technologies

- Python
- MySQL
- Power BI
